# 彩盒折叠预览工作室

浏览器内的盒型折叠预览系统:参数化刀版自动生成、按面印刷贴图、带纸板厚度的分步折叠仿真。
面向包装打样前的客户沟通 —— 不用打实物样,就能看到盒子折起来的样子,并保证折好后各面严丝合缝。

技术栈:**React 18 + TypeScript + three.js + Vite + Zustand**

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5180
npm run build      # 生产构建
npm run validate   # 折叠几何数值校验(81 项,不依赖浏览器)
```

## 五个页面

| 页面 | 功能 |
| --- | --- |
| 盒型库 | 盒型增删改、复制、重命名;天地盖/飞机盒/扣底盒参数化模板 |
| 刀版编辑 | 按长宽高+纸厚自动生成刀版;裁切线(红实线)与压痕线(蓝虚线)分层;SVG 导出/导入识别;缩放与尺寸标注 |
| 印刷面 | 按面板分配贴图、出血位边缘像素外扩、烫金区域蒙版标注 |
| 折叠预览 | 按压痕线分步折叠、时间轴拖动、播放、轨道旋转缩放、截图(带 L/W/H/t 尺寸) |
| 设置 | 白卡/牛皮/覆膜/瓦楞材质、出血默认值、本地数据管理 |

## 厚度补偿如何做到"严丝合缝"

这是本系统的核心,所有约定都在 `src/lib/` 的纯数学模块里,可被 Node 直接校验:

1. **内表面网络**:整个刀版平面网络定义在纸板内表面平面 (z=0),板件向纸外 (-z) 挤出厚度 `t`。
2. **内表面压痕轴**:每块板绕自身内表面上的压痕线旋转。折好后相邻两板的内壁数学共面 —— 零间隙;
   两板实体分处轴的两侧 —— 零体积重叠。
3. **角部让位缺口**:相邻立墙的防尘耳/侧片在刀版上内缩一个 `t` 宽度,折起后角部不发生实体干涉(真实刀模的标准做法)。
4. **包面铰接补偿**:飞机盒盖前墙这类"包在另一块板外侧"的三连折结构,铰接边按折叠运动链精确偏移
   (`src/lib/templates.ts` 中 `hingeOffset`),消除多板厚度累积。
5. **数值校验**:`scripts/validate.ts` 对 7 组工况(纸厚 0.4~2.5mm)验证
   贴合面偏差 < 0.01mm、结构板实体零重叠、锁底中线精确对碰、刀版压痕全覆盖。

## 目录结构

```
src/
  types.ts                 共享类型(尺寸单位均为 mm)
  lib/
    geometry2d.ts          2D 多边形、刀版裁切/压痕推导
    foldMath.ts            4x4 矩阵、绕轴折叠运动学、AABB 重叠检测
    templates.ts           三种盒型的参数化板件网络
    materials.ts           材质预设与烫金材质
    svg.ts                 刀版 SVG 导出/导入与压痕识别
    printTexture.ts        贴图出血外扩
  three/sceneBuilder.ts    挤出实体、双面材质、烫金层、矩阵组合
  components/
    FoldViewer.tsx         three 场景 + 轨道控制 + 尺寸标注叠加层
    DielineThumb.tsx       刀版 SVG 缩略图
  pages/                   五个页面
  store/useStore.ts        Zustand 状态 + localStorage 持久化

```

## SVG 导入约定

- 本系统导出的 SVG 带 `data-meta` 元数据,再次导入可**无损重建**完整折叠层级。
- 第三方刀版 SVG:自动识别蓝色 (`#2563eb` 等) 或虚线 (`stroke-dasharray`) 线条为压痕,
  以最大面板为根建立父子折叠关系,默认折角 90°,可在后续版本扩展手动指定。

## 已知边界

- 折叠是绕压痕轴的刚体转动(理想压痕),未模拟纸张弯曲回弹与褶皱。
- 锁底/插舌按标准角度近似,未做卡扣受力分析。
- 数值结果用于沟通展示,不替代正式打样的物理测试。
